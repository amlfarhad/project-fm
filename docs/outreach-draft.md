Subject: Realtime 2D tactical reconstruction from match video

I am building Project FM, a local realtime tactical reconstruction system for soccer clubs. It ingests match video from a file, stream URL, or browser capture and turns it into a Football Manager-style 2D tactical map with players, teams, identity corrections, quality warnings, and CSV/JSONL exports.

The current build runs locally on a MacBook Air for development and is designed to move to a small stadium workstation for low-latency matchday use. The analyst workflow is:

1. Ingest a full-match file, stream URL, or browser video source.
2. Generate a 2D pitch state with observed and estimated players.
3. Correct team, shirt number, name, and role when needed.
4. Export tactical state data for review.

I am looking for a short technical trial with club-supplied footage. I can send a one-command runbook and a pass/fail trial report format so your staff can quickly judge whether this is useful for live tactical analysis.
